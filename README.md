# Dakahlia 360°: النموذج الأولي

تجربة رقمية موحدة لمحافظة الدقهلية: **بوابة خدمات** (المرحلة 01 — جاهزة للتجربة)، **خريطة مشروعات** (02)، **اكتشف الدقهلية واستثمر** (03).

> نموذج أولي للعرض والنقاش، وليس موقعًا حكوميًا رسميًا. لا يدّعي أي تكامل مع أنظمة حكومية.

## التشغيل

```bash
python3 serve.py 5360
```
ثم افتح `http://localhost:5360`. لا يحتاج أي build أو تثبيت، ويعمل كما هو على GitHub Pages.

## User Journeys

1. **مواطن عنده احتياج:** يكتب بالعامية («عايز أطلع ترخيص لمحل») ← نتيجة الخدمة ← الجهة والقناة الرسمية ← اختيار المركز.
2. **مواطن عنده مشكلة:** الشكاوى ← نوع المشكلة ← رقم/رابط القناة الرسمية.
3. **مواطن يبدأ من منطقته:** المراكز ← مركزه ← الجهة المحلية والخدمات ← المشروعات ← المعالم.
5. **زائر:** اكتشف ← مدينة مميزة أو معلم ← المصدر ← المنطقة ومشروعاتها.
6. **مستثمر:** الاستثمار ← المقومات ← مسار الجهات (الأرض، التأسيس، التراخيص) ← خدمات البوابة.
4. **المساعد الذكي:** متاح في كل صفحة؛ يفهم العامية، يرشّح الخدمة، يرفض ذكر رسوم أو مدد غير موثقة، ويربط المركز إن ذُكر.

## Architecture

```
index.html              الهيكل + التنقل الموحد
serve.py                سيرفر تطوير محلي بدون كاش
assets/css/app.css      Design system (tokens + components + responsive)
assets/js/app.js        Router (hash) + سلوكيات عامة (بحث، اقتراحات، فلاتر)
assets/js/ui.js         مكونات مشتركة (كروت، شارات، مصادر، أيقونات)
assets/js/lib/search.js محرك البحث العربي (تطبيع، stemming خفيف، مرادفات عامية، scoring)
assets/js/assistant.js  طبقة المساعد (retrieval من الدليل فقط — قابلة للاستبدال بـ LLM)
assets/js/data/*.js     البيانات منفصلة عن الواجهة (projects.js = بيانات تجريبية، geo.js = OpenStreetMap)
assets/js/views/map.js  الخريطة (Leaflet يُحمّل عند الحاجة فقط + خرائط OpenStreetMap)
assets/js/views/*.js    الصفحات
```

## سياسة البيانات

- `meta.js` يحفظ كل مصدر رسمي وحالة فحص الرابط وتاريخه.
- العناوين، الأرقام التفصيلية، المستندات، الرسوم، المدد: **«غير متحقق منها حالياً»** حتى تأكيدها من الجهة.
- أي بيانات توضيحية تحمل شارة **«بيانات تجريبية»** (مستندات ترخيص المحل، وكل مشروعات الخريطة).
- قائمة المراكز وأرقام الطوارئ تحتاج مراجعة نهائية مع الموقع الرسمي للمحافظة (لم يكن متاحًا للفحص الآلي).
- **كل مشروعات الخريطة بيانات تجريبية** بأسماء عامة مكتوب عليها «(مثال)»، وعليها شارة واضحة. تُستبدل ببيانات المحافظة الرسمية (الاسم، الموقع الدقيق، الجهة، الحالة، آخر تحديث، رابط المصدر).
- مواقع المراكز وحدود المحافظة من OpenStreetMap (تقريبية، وليست حدودًا رسمية).
- آخر فحص للروابط الخارجية: 2026-11-26. موقع المحافظة الصحيح `dakahliya.gov.eg` كان يعرض خطأ وقت الفحص.
- محتوى «اكتشف» (`data/discover.js`): معلومات نوعية قصيرة، كل منها بمصادر (رسمية / صحفية / موسوعية) مع نوع المصدر ظاهر. لا أسعار ولا مواعيد ولا أرقام.
- الفرص الاستثمارية: لا تُعرض أي فرصة إلا المعلنة رسميًا؛ حاليًا لا توجد، والبطاقة الظاهرة نموذج فارغ عليه شارة «بيانات تجريبية».

## المراحل
- **01** بوابة الخدمات · **02** خريطة المشروعات · **03** اكتشف واستثمر
- **04** تجربة موحدة: بحث موحد (palette + صفحة نتائج)، روابط متبادلة (خدمة ↔ مشروعات القطاع، جهة ↔ مشروعاتها، مركز ↔ خدمات ومشروعات ومعالم)، تنقل موحد.
- **05** طبقة الذكاء: المساعد يسترجع من كل بيانات المنصة، يفهم سياق الصفحة («فين أقدم؟» داخل صفحة خدمة)، يتابع المحادثة («وفي جمصة؟»)، ويذكر المصدر تحت كل إجابة. لا يولّد رسومًا أو مددًا أو إجراءات.
- **06** التصميم والجودة: نظام تصميم مبني على skill «landing-page-design» (مقاسات خطوط ومسافات وانحناءات من الجداول المعتمدة، خلفيات مسطحة، أيقونات Phosphor، حركة بمنحنى موحد، قائمة عائمة، قائمة موبايل كاملة، ظهور الأقسام عند التمرير، صفحة 404، صورة مشاركة og.png). استثناء موثق: خط IBM Plex Sans Arabic لأن خطوط الـ skill لا تدعم العربية.

## طبقة تطوير الأفكار والمشروعات (إضافة فقط)
| المسار | الوظيفة |
|---|---|
| `#/ideas` | صفحة الأفكار العامة (بسيطة): خارطة المراحل وفلتر القطاع، ولكل فكرة «ملف المشروع» و«جرّب النموذج» |
| `#/team` | مساحة الفريق (داخلية، غير ظاهرة في القائمة؛ رابط صغير في الفوتر): لوحة مسار التطوير، ترتيب، Kanban، وروابط المعمل والاستوديو. فتحها يفعّل «وضع الفريق» في المتصفح ليُظهر أدوات الربط والتحويل في صفحات المشروعات |
| `#/idea/:id?tab=` | مساحة تطوير الفكرة: تحليل المشكلة، الحل، تطوير المشروع، الأثر، التقييم (5 معايير بأوزان)، الروابط والدمج، ربط المشروعات، تصدير JSON |
| `#/idea/:id/proposal` | ملف مشروع احترافي قابل للطباعة وحفظه PDF |
| `#/lab?tool=` | معمل تطوير الأفكار: توليد أفكار، من مشكلة إلى فكرة، تطوير فكرة، دمج أفكار، اكتشاف الفرص في 12 قطاعًا |
| `#/studio?idea=` و `#/proto/:type` | استوديو النماذج: حجز، متابعة (بخريطة)، بلاغات، لوحة مؤشرات، موقع تعريفي، موبايل؛ والخريطة والبوابة الحاليتان بدل التكرار |
| `#/project/:id` و `#/project/:id/brief` | ذكاء المشروع: مشروعات مرتبطة بأسبابها، أفكار مرتبطة وربطها، فرص تطوير قابلة للتحويل لأفكار، وملخص مشروع قابل للطباعة |

- التخزين: `localStorage` في متصفح المستخدم (`d360.ideas.*`، `d360.proto.*`)، لا يوجد خادم.
- الذكاء: محاكاة قائمة على قواعد في `lib/innovation.js`، معلنة في كل شاشة. لا يوجد AI API متصل. الواجهة مصممة بحيث يمكن استبدال الدوال بنموذج لغوي لاحقًا.
- كل بيانات النماذج والمشروعات تجريبية ومعلّمة.
